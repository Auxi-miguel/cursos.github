🤔 Git vs GitHub

📦

Git

Sistema de control de versiones. Corre localmente en tu computadora.

Local Gratis
🌐

GitHub

Plataforma en la nube para alojar repos y colaborar con otros.

Remoto Colaborativo

Analogía: Git es como guardar versiones de un documento en tu PC.
GitHub es como subir ese documento a Google Drive para compartirlo.

🔧 Configuración Inicial

Abre tu terminal (recomendado: Git Bash) y ejecuta:

# Configurar tu identidad
git config --global user.name "Tu Nombre"
git config --global user.email "tu@email.com"

# Rama principal por defecto
git config --global init.defaultBranch main

# Guardar credenciales (Windows)
git config --global credential.helper manager

# Verificar configuración
git config --list
⚠️

VS Code + Git Bash: Presiona Ctrl + Shift + P → "Terminal: Select Default Profile" → "Git Bash"

📁 Comandos Básicos

git init
git add .
git commit -m "msg"
git push
Comando Descripción
git init Inicializa un repositorio Git en la carpeta actual
git status Muestra el estado de tus archivos
git add . Agrega TODOS los archivos al área de staging
git commit -m "msg" Guarda los cambios en el historial
git log --oneline Historial compacto de commits

🌐 Conectar con GitHub

# 1. Crea un repo VACÍO en GitHub (sin README)

# 2. En tu terminal, dentro de tu proyecto:
git remote add origin https://github.com/TU-USUARIO/mi-repo.git

# 3. Renombra la rama a main
git branch -M main

# 4. Sube tu código (primera vez)
git push -u origin main

# 5. Para subir cambios futuros:
git push
💡

Tip: Cuando te pida contraseña, pega tu Token PAT (no tu contraseña de GitHub)

🛡️ Archivo .gitignore

Archivos que NO quieres subir a GitHub:

# Archivos del sistema
.DS_Store
Thumbs.db

# Dependencias
node_modules/

# Variables de entorno (contraseñas, API keys)
.env

# IDEs
.vscode/
.idea/

# Archivos de build
dist/
build/

¿Cómo crearlo? En VS Code: click derecho en la carpeta raíz → "Nuevo archivo..." → escribe .gitignore (con el punto al inicio)

🌿 Ramas (Branches)

Las ramas te permiten trabajar en nuevas funcionalidades sin romper la rama principal.

# Ver ramas existentes
git branch

# Crear una nueva rama
git branch nombre-rama

# Cambiar a otra rama
git checkout nombre-rama

# Crear y cambiar en un solo paso
git checkout -b nombre-rama

# Fusionar una rama en tu rama actual
git merge nombre-rama

🤝 Colaboración: Fork & Pull Request

🍴

Fork

Crea una copia del repo de otra persona en tu cuenta. Se hace desde la interfaz web de GitHub.

🔀

Pull Request (PR)

Pides que revisen y fusionen tus cambios en el repo original. Es el corazón de la colaboración.

🚀 GitHub Pages

Publica tu página web gratis directamente desde tu repo.

¿Público o privado?

Público → GitHub Pages es gratis
Privado → Necesitas GitHub Pro (pago)

Cómo activarlo:

  1. Ve a tu repo → Settings
  2. Pestaña Pages (menú lateral izquierdo)
  3. Source: Deploy from a branch
  4. Branch: main / Folder: / (root)
  5. Click Save
  6. Espera 1-2 minutos
  7. URL: https://tu-usuario.github.io/mi-repo/

🐛 Errores Comunes y Soluciones

❌ 'git' no se reconoce

Git no está en el PATH. Abre VS Code desde CMD o cambia la terminal a Git Bash.

❌ failed to push (rejected)

El remoto tiene cambios que tú no tienes. Ejecuta: git pull origin main --allow-unrelated-histories

❌ refusing to merge unrelated histories

Creaste el repo en GitHub con README. Usa: git pull origin main --allow-unrelated-histories

❌ Authentication failed

Usaste tu contraseña en vez del Token PAT. Borra credenciales y usa el token.
